# Мод Castle Fight

## Обзор
Castle Fight - это мод для игры Horde, который вводит комплексный режим игры с битвами замков. Этот мод интегрирует юниты из различных других модов и предоставляет специализированные скрипты для включения динамичной замковой войны на специальных картах.

## Особенности

### Интеграция юнитов
Мод агрегирует и улучшает юнитов из нескольких источников:
- **Юниты Славян (Slavyane)**: Включает воинов вроде Beamman, Crossbowman, Fireforged Warrior (Паладин), здания такие как Кузница, Лесопилка, Лаборатория, Ферма, Казарма, Конюшня и другие.
- **Юниты Магов**: Добавляет мощных существ вроде Минотавра, Скелета, различных магов (Фантом, Виллур, Икон, Ольга), и Медвежьих всадников (Bearmen).
- **Улучшенное производство**: Модифицирует существующие здания для производства новых юнитов, с требованиями к другим модам вроде BlacksmithMod.

### ИИ-персонажи
Вводит специализированных ИИ-оппонентов:
- Случайный ИИ
- Случайный ИИ только ближнего боя
- Случайный ИИ только дальнего боя
- Случайный ИИ с Церковью

### Игровые системы
Реализует продвинутые механики игры через пользовательские системы:
- **Система атаки вдоль пути**: Контролирует движение и бой юнитов вдоль предопределенных путей
- **Система баффов**: Управляет временными улучшениями юнитов
- **Система дипломатии**: Обрабатывает альянсы игроков и конфликты
- **Система доходов**: Управляет генерацией ресурсов
- **Система воскрешения**: Позволяет механики воскрешения юнитов
- **Система спавна**: Контролирует спавн юнитов
- **Система произведенных юнитов**: Отслеживает и управляет вновь созданными юнитами
- **Система улучшаемых зданий**: Включает прогрессию зданий
- **Система ИИ**: Предоставляет интеллектуальное поведение оппонентов
- **Система поиска баланса**: Автоматизированная система тестирования баланса юнитов

### Карты
Включает множество специализированных боевых карт:
- Битва замков - две тропы (3х3)
- Битва замков - лесная тропа (3х3)
- Битва замков - лесная тропа с мостами (3х3)
- Битва замков - перекресток (1x1x1x1)
- Битва замков - перекресток (2x2x2)
- Битва замков - союзник в тылу врага (2x2x2)
- Битва замков - царь горы (1x1x1x1)
- Битва замков - царь горы (2-6)
- Битва замков - царь горы (2x2x2)
- Битва замков - тест баланса

### Тестирование баланса
Система поиска баланса предоставляет возможности автоматизированного тестирования баланса:
- Спавнит юнитов на множественных полях боя одновременно
- Тестирует производительность юнитов при разных размерах армий (100%, 50%, 10%)
- Собирает статистику выживаемости
- Выводит детальные таблицы баланса для балансировки игры

## Установка
1. Убедитесь, что у вас установлена базовая игра Horde
2. Поместите папку ModData в директорию модов вашей игры
3. Включите мод через менеджер модов игры
4. Выберите карту Castle Fight для начала игры

## Требования
- Игра Horde версии 0.79pre или совместимая
- Может требовать дополнительные моды для полного состава юнитов (BlacksmithMod и т.д.)
