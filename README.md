# Мод Castle Fight

## Описание
Castle Fight - это новый режим игры для Орды, который вдохновлен картами CastleFights из Warcraft 3. В данном режиме ваша цель эффективно потратить ограниченные ресурсы, чтобы собрать комбинацию армии превосходящую вражескую. Для этого вы будете строить  производственные здания, которые будут автоматически производить войнов с собственным интеллектом. Данные здания можно улучшать, чтобы они производили более сильных войнов.

### ИИ-персонажи
Вводит специализированных ИИ-оппонентов:
- Случайный ИИ
- Случайный ИИ только ближнего боя
- Случайный ИИ только дальнего боя
- Случайный ИИ с Церковью

### Карты
Включает множество специализированных боевых карт:
- Битва замков - две тропы (3х3)
- Битва замков - лесная тропа (3х3)
- Битва замков - лесная тропа с мостами (3х3)
- Битва замков - перекресток (1x1x1x1)
- Битва замков - перекресток (2x2x2)
- Битва замков - союзник в тылу врага (2x2x2)
- Битва замков - царь горы (1x1x1x1)
- Битва замков - царь горы (2-6)
- Битва замков - царь горы (2x2x2)
- Битва замков - тест баланса
